# 메일 형식과 보고 형식 작성 예

agent-tone §3.6과 §8의 적용 예입니다. 사내 회의록 요약 도구를 평가했다고 가정한 가상 사례이며,
실제 평가 결과가 아닙니다. 대괄호는 실제 자료로 채울 자리입니다. 수치를 지어내 채우지 않습니다(§6.5).

## 같은 평가 결과

평가자가 확인한 사실은 다음과 같다고 가정합니다.

- 발언자 구분: 시험 회의 [n]건 전부에서 발언자를 정확히 구분함
- 결정 사항: [n]건 중 [n]건에서 회의 말미의 결정 사항이 요약에 빠짐
- 용어: 같은 제품명이 회차마다 다르게 표기됨
- 외부 참석자: 발언 기록의 저장 범위를 문서에서 확인하지 못함

## 메일 형식

수신자에게 결과를 알리고 조치를 요청하는 글입니다. 합쇼체로 쓰고 인사말 없이 시작합니다.

```text
회의록 요약 도구 1차 평가 결과를 공유드립니다.

발언자 구분은 시험 회의 [n]건 전부에서 정확했습니다. 다만 [n]건 중 [n]건에서 회의 말미의 결정
사항이 요약에 빠졌고, 같은 제품명이 회차마다 다르게 표기됐습니다. 외부 참석자 발언을 어디까지
저장하는지는 제공된 문서에서 확인하지 못했습니다.

다음 릴리즈 전에 결정 사항 추출 단계와 용어 사전 적용을 검토해 주십시오. 외부 참석자 발언의 저장
범위는 운영 정책 문서로 회신해 주시기 바랍니다.

관련 문서: [평가 결과 보고서 경로]
```

## 보고 형식: 문서형

판단 근거를 정리해 보고하는 글입니다. 결론을 먼저 쓰고, 블록마다 정해진 종결을 씁니다(§8.3).

```text
총평
1차 릴리즈 기준으로 운영 가능한 수준으로 판단됨. 발언자 구분은 견고하나, 결정 사항 누락과 용어 표기
불일치는 다음 릴리즈 전 보완 필요

개요: 회의 녹취를 받아 발언자별 요약과 결정 사항 목록을 생성하는 도구로, 사내 회의실 녹음 장비의
음성 파일을 입력으로 사용함

강점
- 정확한 발언자 구분: 시험 회의 [n]건에서 발언자 [n]명을 모두 구분함

개선기회
[참고: 둘째 항목은 다음 릴리즈 참고 사항임]
- 결정 사항 누락: [n]건 중 [n]건에서 회의 말미의 결정 사항이 요약에 빠짐
  예: 마지막 [n]분의 '[결정 문구]' 발언이 결정 사항 목록에 없음
- 용어 표기 불일치: 같은 제품명을 회차마다 다르게 표기함
  예: '[표기 A]'와 '[표기 B]'가 같은 회의 요약 안에 함께 나타남
- 저장 범위 미확인: 외부 참석자 발언의 저장 범위가 명확하지 않음

제언
- 결정 사항 추출 단계 추가: 요약과 별도로 결정·담당·기한을 추출하는 단계를 두어야 함
- 용어 사전 적용: 제품명·조직명 표기를 사전 기준으로 통일해야 함
- 저장 범위 명시: 외부 참석자 발언의 저장·삭제 기준을 운영 정책에 명시해야 함
```

## 보고 형식: 장표형

같은 내용을 결과 장표 한 장으로 옮긴 구성입니다(§8.9). 실제 장표에서는 왼쪽에 비교 차트를 둡니다.

```text
제목    3. 평가 결과 > 회의록 요약                [대상 A] [회의록 요약] [대상 C]
메시지  결정 사항 추출과 용어 표기 일관성 확보 필요

[비교 차트: 기준값 vs 측정값]
| 항목        | 점수 | 근거                                                    |
| 발언자 구분 | [n]  | 시험 회의 [n]건 전부 정확                               |
| 정확성      | [n]  | 결정 사항 누락 [n]건 → 요약 활용 시 수작업 확인 필요    |
|             |      |   예: 마지막 [n]분의 '[결정 문구]' 누락                 |
| 일관성      | [n]  | 같은 제품명의 표기가 회차마다 다름                      |
| 저장 범위   | N/A  | 운영 정책 문서 미제공으로 확인 불가                     |

Result  ■ 결정 사항 추출 단계 추가  ■ 용어 사전 기반 표기 통일 필요
```

## 피할 결과와 기대 결과

| 상황 | 피할 결과 | 기대 결과 |
| :--- | :--- | :--- |
| 강점 | `직관적이고 효율적인 요약 제공` | `정확한 발언자 구분: 시험 회의 [n]건에서 발언자 [n]명을 모두 구분함` |
| 장표 메시지 | `평가 결과` | `결정 사항 추출과 용어 표기 일관성 확보 필요` |
| 문제 | `일부 정확도 이슈가 있음` | `결정 사항 누락: [n]건 중 [n]건에서 결정 사항이 요약에 빠짐` |
| 미확인 | `외부 참석자 발언을 저장하지 않음` | `저장 범위 미확인: 외부 참석자 발언의 저장 범위가 명확하지 않음` |
| 제언 | `거버넌스를 강화할 필요가 있습니다.`(합쇼체 혼입) | `용어 사전 적용: 제품명·조직명 표기를 사전 기준으로 통일해야 함` |
| 측정 불가 | 점수를 추정해 기입 | `N/A`와 사유 한 줄 |
| 짝 맞추기 | 개선기회 3건, 순서가 다른 제언 2건 | 개선기회와 제언을 같은 순서로 3건씩 대응 |
