# 한국어 Humanizer

AI가 쓴 한국어는 문법이 틀려서가 아니라 **리듬이 균일하고, 번역투가 섞이고, 태도가 과잉 친절해서** 티가 난다. 단어 치환 필터로는 못 잡는다. 문단 단위로 다시 써야 한다.

## 작업 순서

1. 원문의 격식 수준을 먼저 정한다: 합쇼체(-습니다) / 해요체(-요) / 해라체(-다) 중 하나, 문어/구어 여부. 글 전체에서 흔들리지 않게 유지한다.
2. 아래 카탈로그의 패턴을 찾아 문장이 아니라 **문단 단위로 재작성**한다. 패턴 하나만 고치면 주변 문장과 리듬이 어긋난다.
3. 정보가 빠지지 않았는지 원문과 대조한다. 분량이 20~30% 줄면 정상이다. 오히려 안 줄었으면 상투어를 덜 걷어낸 것이다.
4. 소리 내어 읽는다고 상상하고 리듬을 확인한다. 같은 종결어미가 3문장 이상 연달아 나오면 다시 쓴다.

## 영문 소스 기반 작성 — 번역하지 말고 재서술한다

영문 자료(논문, 기사, 문서)를 바탕으로 한국어 글을 쓸 때 번역체가 생기는 원인은 단어가 아니라 **문장 구조를 영어에서 그대로 가져오기 때문**이다. 후처리로는 못 고친다. 순서를 바꿔야 한다.

1. **추출**: 영문에서 사실·수치·논지·인용을 한국어 개조식 메모로 뽑는다. 이 단계에서는 문장을 만들지 않는다.
2. **차단**: 영문 원문을 더 이상 보지 않는다. 문장 구조가 딸려오는 경로를 끊는 것이 목적이다.
3. **작성**: 메모만 보고, 아래 문체 프로필 중 하나로 한국어 글을 처음부터 쓴다. "이 내용을 한국 기자/작가가 처음부터 한국어로 썼다면 어떤 문장이 됐을까"가 기준이다.
4. **점검**: 완성 후 패턴 카탈로그로 잔여 번역투를 훑는다.

영어 구조가 딸려왔는지 확인하는 신호:

| 영어 구조의 흔적 | 한국어다운 문장 |
|---|---|
| 보고서**는** 사용률이 늘었다**는 것을 보여준다** (무생물 주어) | 보고서**에 따르면** 사용률이 늘었다 / 사용률이 늘어난 **것으로 나타났다** |
| 관계절이 줄줄이 붙은 3줄짜리 한 문장 | 문장을 두세 개로 쪼갠다. 한 문장 한 정보 |
| 이 기술은 널리 사용**되고 있다** (진행형 직역) | 이 기술은 널리 **쓰인다** |
| **~함으로써** 비용을 줄였다 (by -ing) | 비용을 줄이**려고** ~했다 / ~해서 비용을 줄였다 |
| 반대**에도 불구하고** (despite) | 반대**에도** / 반대를 무릅쓰고 |
| **만약** 실패한다**면** (if 직역) | 실패하**면** ("만약" 삭제) |
| 사용자**들**은, 기업**들**이 (복수형 직역) | 사용자는, 기업이 (문맥이 복수를 담는다) |
| **하나의** 해법, **그** 문제 (관사 직역) | 해법, 문제 (관사어 삭제) |
| 성장**을 위한** 전략 (for 직역) 남발 | 성장 전략 / 성장**하려는** 전략 |

## 문체 프로필

요청에 맞는 프로필을 골라 글 전체에 일관되게 적용한다. 지정이 없으면 보도체를 기본으로 한다.

### 보도체 (뉴스 기사)

- 해라체 "-다" 종결. 첫 문장(리드)에 핵심 사실을 다 넣는다: 누가, 무엇을, 언제.
- 한 문장에 정보 하나. 문장은 짧게, 수식어는 최소로.
- 전달동사를 상황에 맞게 고른다: 밝혔다, 전했다, 설명했다, 지적했다, 강조했다, 내다봤다. "말했다"만 반복하지 않는다.
- 전망·추측은 관례 표현으로: "~할 전망이다", "~것으로 보인다", "~것으로 알려졌다", "~로 나타났다", "~로 풀이된다".
- 수치는 구체적으로, 첫 등장 시 기준을 함께: "전년 대비 12% 늘어난 3억 달러".
- 감정·평가 형용사를 쓰지 않는다. 판단은 인용이나 수치가 대신하게 한다.

### 다큐멘터리 내레이션체

- 현재형 서술로 현장감을 만든다: "~한다", "~이다". 과거 사건도 장면 안에서는 현재형이 가능하다.
- 짧은 문장과 여백. 명사형 종결을 적극 활용한다: "그로부터 10년.", "모든 것의 시작이었다."
- 시간·장소 제시로 장면을 전환한다: "1997년 겨울.", "사흘 뒤, 같은 자리."
- 구체적 장면에서 시작해 일반 논지로 넓힌다. 추상적 주장으로 시작하지 않는다.
- 질문을 던져 호흡을 바꾼다: "무엇이 이들을 움직였을까." (남발 금지, 글 하나에 한두 번)
- 정보 나열이 아니라 서사다. 사실 사이에 인과와 긴장을 만든다.

## 패턴 카탈로그

### 1. 번역투 — 가장 큰 AI티

영어 구문을 직역한 흔적. 조사와 동사로 풀어낸다.

| AI 번역투 | 자연스러운 한국어 |
|---|---|
| 이 문제**에 대해** 논의했다 | 이 문제**를** 논의했다 |
| 테스트**를 통해** 검증한다 | 테스트**로** 검증한다 |
| 성능**에 있어서** 중요하다 | 성능**에** 중요하다 / (통째로 삭제) |
| 오류**로 인해** 실패했다 | 오류 **때문에** 실패했다 / 오류가 나서 실패했다 |
| 시스템**에 의해** 처리된다 | 시스템**이** 처리한다 (피동→능동) |
| 확인**하는 것이** 필요합니다 | 확인**해야** 한다 (명사화→동사) |
| 중요한 의미**를 가진다** | 중요한 의미**가 있다** |
| 가장 인기 있는 도구 **중 하나** | 널리 쓰이는 도구 |
| **그것은/이것은** ~이다 | (대명사 삭제, 필요하면 명사 반복) |
| **당신**의 코드 | (무조건 삭제 또는 생략) |
| **저는** ~라고 생각합니다 | (주어 생략 — 한국어는 주어 생략이 기본값) |

### 2. 상투어·공허한 수식어 — 삭제하거나 구체적 사실로 교체

- 다양한, 효율적으로, 체계적으로, 원활한, 성공적으로, 핵심적인, 필수적인, 전반적으로, 지속적으로
- "매우 중요합니다", "큰 도움이 됩니다", "아무리 강조해도 지나치지 않습니다"
- "빠르게 변화하는 시대에", "~의 여정", "게임 체인저", "한 단계 끌어올리다"
- "단순히 X가 아니라 Y입니다" (영어 "not just X, but Y"의 직역)
- "~뿐만 아니라 ~도" 문장마다 반복

교체 원칙: 수식어를 지우고 그 자리에 **구체적 수치·사례·행동**을 넣는다. "성능이 크게 개선됩니다" → "응답이 1.2초에서 0.3초로 줄었다". 넣을 사실이 없으면 문장째 지운다.

### 3. 과잉 친절 — 서비스 말투 전부 삭제

- "물론입니다!", "네, 좋은 질문입니다", "기꺼이 도와드리겠습니다"
- "도움이 되셨길 바랍니다", "궁금한 점이 있으시면 언제든지 말씀해 주세요"
- "~해 보시는 것을 추천드립니다" → "~하면 된다" / "~해라" (격식 수준에 맞춰)
- 서두의 질문 되풀이("~가 궁금하신가요? 오늘은 ~를 알아보겠습니다")

사람은 글에서 독자를 접객하지 않는다. 본론으로 바로 들어간다.

### 4. 헤징 — 단정할 수 있으면 단정한다

- "~할 수 있습니다"가 반복되면 절반은 "~한다"로 바꾼다. 실제로 가능성을 말하는 문장만 남긴다.
- "일반적으로", "대체로", "경우에 따라 다를 수 있지만" — 예외가 정말 중요한 경우가 아니면 삭제.
- 한 문단 안에서 양쪽에 다 걸치는 서술("A가 좋지만 B도 장점이 있습니다") — 판단을 내리고 한쪽을 권한다.

### 5. 리듬 — 종결어미와 문장 길이의 변주

AI 한국어의 가장 깊은 티. 모든 문장이 비슷한 길이에 같은 어미("-습니다" 또는 "-다")로 끝난다.

- 문장 길이를 의도적으로 흔든다. 긴 문장 뒤에 짧은 문장. 아주 짧아도 된다.
- 해라체 문어: "-다" 사이에 "-는 것이다", 명사형 종결("~한 셈."), 의문형("왜 그럴까.")을 섞는다.
- 해요체 구어: "-요", "-죠", "-는데요", "-거든요"를 섞는다. 단, 격식 수준 자체는 유지.
- 문단 첫머리의 접속부사(또한, 더불어, 아울러, 뿐만 아니라, 하지만, 그러나)는 대부분 지워도 문맥이 통한다. 지워라.
- 셋씩 나열하는 습관(rule of three)을 깬다. 둘만 쓰거나 넷을 쓰거나, 하나만 깊게 쓴다.

### 6. 구조 — 문서 형태의 AI티

- 짧은 글에 헤더·불릿을 쓰지 않는다. 세 문단이면 그냥 세 문단으로 쓴다.
- **볼드 강조**를 걷어낸다. 문장 자체가 강조를 실어야 한다.
- "다음과 같습니다:" 도입부 + 콜론 + 목록 패턴을 줄인다. 목록이 정말 필요한 자료성 내용에만 쓴다.
- 마지막의 "결론적으로", "요약하자면", "마치며" 요약 문단은 대개 삭제한다. 본문에서 이미 말한 내용이다.
- 이모지 금지 (원문이 이미 쓰고 있는 경우 제외).

## 최종 점검

다시 읽으면서 자문한다:

- 이 글을 처음 보는 사람이 "AI가 썼네"라고 느낄 문장이 남아 있는가?
- 같은 어미로 끝나는 문장이 3개 이상 연달아 있는가?
- 지워도 의미가 안 변하는 단어가 있는가? (있으면 지운다)
- 필자의 판단이 드러나는가, 아니면 양쪽에 다 걸치고 있는가?

하나라도 걸리면 그 문단을 다시 쓴다.
