# 한국어 표현 대안

`agent-tone` §2.3의 적용 예입니다. 추상적인 표현이나 반복되는 부정형 설명을 고칠 때 참고합니다.
아래 문장은 샘플의 직접 인용이 아니라 사용자 선호를 반영해 만든 교정 예입니다.

먼저 원문이 뜻하는 동작이나 판단을 확인합니다. 대안은 서로 바꿔 쓸 수 있는 동의어 목록이
아닙니다. 정보가 부족하면 주체·대상·기준을 확인하고, 표현을 풍부하게 만들려고 사실을 추가하지
않습니다. 같은 개념은 같은 용어로 유지합니다.

## 축

| 원래 표현과 문맥 | 대안 | 선택 기준 |
| :--- | :--- | :--- |
| 세 가지 축으로 평가 | 세 가지 기준으로 평가 / 품질·비용·일정별 평가 | 평가 기준 |
| 전략의 두 축 | 두 가지 중점 과제 / 주요 추진 과제 | 실행할 일 |
| 세 축으로 구분 | 세 가지 영역으로 구분 / 유형별 분류 / 부문별 정리 | 분류 대상 |
| 논의의 축 | 주요 쟁점 / 검토 항목 / 논의 주제 | 무엇을 논의하는지 |
| 두 축을 함께 고려 | 두 조건을 함께 검토 / 두 요건을 모두 충족 | 고려 사항인지 충족 요건인지 |
| 책임의 축 | 담당 조직 / 역할 분담 / 책임 범위 | 업무 주체와 범위 |
| 관심사의 축이 겹침 | 검토 범위가 중복됨 / 두 팀이 같은 업무를 담당함 | 범위 중복인지 역할 중복인지 |
| 사업의 중심축 | 주력 사업 / 주요 수익원 / 우선 투자 대상 | 실제 사업상 역할 |

`기준`, `과제`, `영역`을 리듬에 맞춰 번갈아 쓰지 않습니다. 품질·비용·일정은 평가 기준일 수도
있고 관리 항목일 수도 있으므로 문장의 목적을 먼저 확인합니다. 그래프의 좌표축과 기계의 회전축은
기술 용어로 유지합니다.

## 무게가 실립니다

| 뜻하는 판단 | 대안 | 보존할 정보 |
| :--- | :--- | :--- |
| 근거가 더 충분함 | A를 뒷받침하는 근거가 더 충분합니다 / 확인한 자료는 A를 지지합니다 | 근거와 비교 대상 |
| 가능성이 증가함 | [조건]에 따라 A의 가능성이 커집니다 / 현재 자료로는 A가 예상됩니다 | 조건과 불확실성 |
| 우선순위가 높아짐 | A를 우선 검토합니다 / A의 처리 순서를 앞당깁니다 | 실제 결정인지 제안인지 |
| 자원 배분이 증가함 | A에 예산을 더 배정합니다 / A의 담당 인원을 늘립니다 | 배분 대상과 확인된 변경 |
| 지지가 늘어남 | A를 지지하는 의견이 늘었습니다 / [주체]가 A를 지지했습니다 | 누가 무엇을 지지했는지 |
| 요구 조건을 더 잘 충족함 | A가 [요건]을 충족합니다 / [기준]에서는 A가 더 적합합니다 | 기준과 평가 범위 |
| 영향을 더 크게 미침 | 이번 결정에는 [요인]의 영향이 컸습니다 / [요인]이 결과를 좌우했습니다 | 입증된 영향과 인과 강도 |
| 논의가 한 항목에 집중됨 | 이번 검토에서는 A를 중점적으로 확인합니다 / 주요 논의 대상은 A입니다 | 검토 범위 |

가능성을 말한 원문을 확정된 결정으로 고치지 않습니다. 예산이나 인원 증가를 확인하지 않았다면
자원 배분 표현을 선택하지 않습니다. `힘을 받습니다`, `기울어집니다`로 바꾸면 같은 모호함이
계속됩니다.

## 남기지 않습니다

| 실제 의도 | 대안 | 구분할 사항 |
| :--- | :--- | :--- |
| 중복 문장 편집 | 중복 설명을 삭제합니다 / 같은 내용은 한 번만 설명합니다 | 이미 있는 문장을 고치는 일 |
| 문서 범위 지정 | 최종 결정과 근거를 정리합니다 / 제출본에는 확정된 결과를 수록합니다 | 독자가 읽을 내용 |
| 특정 항목 제외 | 초안은 제출 대상에서 제외합니다 / 내부 메모는 본문에서 제외합니다 | 제외 대상이 요지인 경우 |
| 핵심만 요약 | 결과와 후속 조치를 요약합니다 / 판단에 필요한 근거를 제시합니다 | 요약 목적 |
| 임시 파일 정리 | 작업이 끝나면 임시 파일을 삭제합니다 | 이미 생성된 파일의 삭제 시점 |
| 정보 미수집 | [정보]는 수집하지 않습니다 | 수집 단계의 정책 |
| 정보 비저장 | [정보]는 저장하지 않습니다 / [기간] 뒤 삭제합니다 | 비저장과 기간 후 삭제는 별개 |
| 변경 이력의 위치 지정 | 변경 경위는 이력 문서에 기록합니다 / 본문에는 현재 동작을 설명합니다 | 정보의 위치 |
| 불확실성 표시 | 미확인 항목은 별도로 표시합니다 / 추가 확인이 필요한 내용을 구분합니다 | 불확실성 자체를 숨기지 않음 |

긍정형은 문서의 목적을 직접 설명할 때 사용합니다. 금지·삭제·보존 정책이 요지라면 대상과
조건을 명시한 부정형이 정확할 수 있습니다. `남기지 않습니다`를 피하려고 삭제 사실을 숨기거나
미확인 결과를 확정하지 않습니다.

## 함께 점검할 표현

| 모호한 표현 | 뜻에 맞는 대안 |
| :--- | :--- |
| 무겁게 봅니다 | 우선 검토합니다 / 엄격한 기준으로 검증합니다 / 중요한 위험으로 분류합니다 |
| 방향성을 잡습니다 | 목표를 정합니다 / 추진 방침을 결정합니다 / 비교 기준을 정합니다 |
| 틀을 잡습니다 | 목차를 정합니다 / 항목을 구성합니다 / 입력 형식을 정의합니다 |
| 흐름을 가져갑니다 | [순서]로 설명합니다 / [단계]부터 수행합니다 / [절차]를 유지합니다 |
| 힘을 싣습니다 | 근거를 보강합니다 / 인력을 추가 배치합니다 / [의견]을 지지합니다 |
| 선을 긋습니다 | 적용 범위를 명시합니다 / 책임 범위를 구분합니다 / [요청]을 거절합니다 |
| 여지를 남깁니다 | 변경할 수 있습니다 / 선택 항목으로 둡니다 / 추가 검토가 필요합니다 |
| 담아냅니다 | 결과를 정리합니다 / 사례를 제시합니다 / 기능을 구현합니다 / 자료를 수록합니다 |

이 표는 단어 금지 목록이 아닙니다. 도형의 선, 실제 힘과 무게처럼 대상이 명확한 기술 설명은
그대로 씁니다. 이미 발행된 문서의 인용문과 고유명사도 임의로 교정하지 않습니다.

## 적용 전후 예

**평가 기준**

- 전: 세 가지 축으로 검토하면 비용 절감에 무게가 실립니다.
- 후: 품질·비용·일정을 비교했습니다. 품질과 일정 요건을 모두 충족한 방안 중 비용이 낮은 A안을 권합니다.
- 조건: 실제 비교 결과가 위 내용과 같을 때만 쓸 수 있습니다. 기준이나 결과가 없으면 먼저 확인합니다.

**자료 작성**

- 전: 불필요한 내용은 남기지 않고 실행 방향에 무게를 실었습니다.
- 후: 중복 설명을 삭제하고, 담당자별 작업과 완료 기한을 정리했습니다.
- 조건: 실제로 수행한 편집과 정리 내용이 일치해야 합니다.

**전망의 강도**

- 전: A안에 무게가 실리지만 결정된 것은 아닙니다.
- 후: 현재 검토에서는 A안이 더 적합한 것으로 보입니다. 최종 결정은 추가 시험 뒤에 내립니다.
- 조건: 적합성 판단과 추가 시험 계획이 확인된 경우입니다. 근거가 단순한 선호라면 선호 주체를 씁니다.

**보존 정책**

- 전: 요청 본문은 로그에 남기지 않습니다.
- 후: 요청 본문은 로그에 기록하지 않습니다.
- 조건: 기록 제외라는 의미를 그대로 유지합니다. `요청 정보를 안전하게 관리합니다`로 일반화하지 않습니다.
